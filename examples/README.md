# BetaMoon Examples

The files in this folder are examples for different functions that BetaMoon provides for mod development.

You can use any of most of the examples by placing them in your `.minecraft/lua_scripts/` folder.
** The `04_custom_textures.lua` script relies on texture files in the `.minecraft/lua_scripts/` that are not provided here so they will not work unless you have custom texture files with the specified names! **
